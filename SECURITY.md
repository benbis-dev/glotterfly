# Security Policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting / Security Advisory flow for this repository. Do not open a public issue containing exploit details, credentials, OAuth callback URLs, private page content, or user data.

Include a minimal synthetic reproduction, affected commit/version, expected impact, and any relevant browser version. Replace real URLs/content with local fixtures wherever possible.

## Scope priorities

High-priority reports include credential exposure, callback interception bypasses, arbitrary cross-origin proxying, permission escalation, unsafe model-output rendering, page-to-privileged-runtime message confusion, or requests continuing after explicit user cancellation/logout.
